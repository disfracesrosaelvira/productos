2. Flujo de Subida de Fotos en Tiempo Real

sequenceDiagram
    participant U as Usuario
    participant S as Svelte
    participant ST as Supabase Storage
    participant API as Node API
    participant DB as PostgreSQL
    participant RT as Realtime
    U->>S: Selecciona foto del móvil
    S->>S: Comprime (browser-image-compression)
    S->>ST: upload() directo
    ST-->>S: URL pública
    S->>API: POST /products con URL
    API->>DB: INSERT producto
    DB->>RT: Evento INSERT
    RT-->>S: Notificación WebSocket
    S-->>U: UI actualizada sin recargar

3. Flujo de Stock en Tiempo Real (Ventas)

sequenceDiagram
    participant V as Vendedor
    participant S as Svelte
    participant API as Node API
    participant DB as PostgreSQL
    participant RT as Realtime
    participant C as Otros clientes conectados
    V->>S: Registrar venta
    S->>API: POST /sales
    API->>DB: INSERT sales + sale_items
    DB->>DB: TRIGGER resta stock_quantity
    DB->>RT: Evento UPDATE en variants
    RT-->>S: WebSocket notificación
    RT-->>C: WebSocket notificación
    S-->>V: Confirmación visual
    C-->>C: UI actualizada sin recargar

5. Modelo de Datos (ER)

erDiagram
    CATEGORIES ||--o{ PRODUCTS : contiene
    PRODUCTS ||--o{ VARIANTS : tiene
    PRODUCTS ||--o{ PRODUCT_IMAGES : tiene
    PRODUCTS ||--o{ PRODUCT_TAGS : tiene
    TAGS ||--o{ PRODUCT_TAGS : etiqueta
    VARIANTS ||--o{ SALE_ITEMS : vendido
    SALES ||--o{ SALE_ITEMS : incluye
    PROFILES ||--o{ SALES : registra

    PRODUCTS {
        uuid id PK
        string name
        string description
        string image_url
        timestamp created_at
    }
    CATEGORIES {
        uuid id PK
        string name
        uuid parent_id FK
    }
    VARIANTS {
        uuid id PK
        uuid product_id FK
        string size
        string gender
        string fabric_quality
        string sku
        int stock_quantity
    }
    PRODUCT_IMAGES {
        uuid id PK
        uuid product_id FK
        string image_url
        bool is_primary
    }
    TAGS {
        uuid id PK
        string name
    }
    PRODUCT_TAGS {
        uuid product_id FK
        uuid tag_id FK
    }
    SALES {
        uuid id PK
        date date
        decimal total_amount
        uuid user_id FK
    }
    SALE_ITEMS {
        uuid id PK
        uuid sale_id FK
        uuid variant_id FK
        int quantity
        decimal unit_price
    }
    PROFILES {
        uuid id PK
        string email
        string role
    }
